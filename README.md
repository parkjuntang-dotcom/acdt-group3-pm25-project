# Group 3 — PM2.5, Healthcare Spending & Life Expectancy

ACDT Project 1 final interactive webpage and reproducible analysis materials.

## Open the project

The GitHub Pages site is the interactive webpage. It contains the final model comparison, healthcare-spending buffering check, plain-language glossary, sources and data-period note.

## Repository layout

- `index.html` — self-contained responsive interactive webpage
- `src/` — analysis scripts and validation notes
- `data/` — WHO/WDI-derived panel and model-result CSV files
- `figures/` — system maps and analysis figures
- `documents/` — executive summary, technical documentation, system-map report and narration transcript

## Research question

Does healthcare spending buffer the relationship between PM2.5 air pollution and life expectancy?

## Main result

Higher-spending countries have higher average life expectancy in the 2019 descriptive comparison, but the adjusted models and the formal healthcare × PM2.5 interaction do not establish a reliable buffering effect.

The common WHO observation window used in the analysis is 2010–2019. Please check the course data-period rule before final submission.
